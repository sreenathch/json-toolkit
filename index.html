JSON/YAML Toolkit — free online JSON & YAML diff, converter, tree editor, validator and JWT decoder

JSON/YAML Toolkit is a free, open-source developer tool that runs entirely in your browser. It compares two JSON or YAML documents and lets you merge changes between them, imports a document straight from a URL or a pasted curl command, converts JSON to YAML and back, edits documents in an interactive tree, validates syntax, and decodes or encodes JSON Web Tokens.

There is no account, no advertising and no usage limit. Parsing, diffing, conversion and JWT decoding all happen locally — the app has no backend, and nothing you paste is uploaded anywhere.

Tools

Diff and merge — #diff

Compare two documents side by side. Added, removed, modified and type-changed keys are colour-coded in a collapsible tree, with "Expand Changes" to jump straight to the paths that differ, a search filter, and a "only changes" toggle. Hover any difference to copy that value from one side to the other — single values with the arrow buttons, whole objects and arrays with L→R and R→L. JSON can be compared directly against YAML.

Each side also has a request field: paste a URL or a full curl command — -X, -H, -d, -u and line continuations are all understood — and press Fetch, or Fetch Both to pull both sides at once. This makes it straightforward to diff the same API endpoint across two environments.

JSON ⇄ YAML converter — #converter

Paste either format and pick the output. Conversion runs as you type and the result copies with one click. Useful for moving between a Kubernetes manifest, a CI configuration file and a JSON API payload.

Interactive tree editor — #visualizer

Render a document as an expandable tree and edit it in place: click a value to change it, click a key to rename it, add a string, number, boolean, null, object or array, or delete a node. Expand to a chosen depth, or search by key path.

Validator — #validate

Check syntax and get the failing line with surrounding context. Common mistakes — unquoted keys, single-quoted strings and trailing commas — are repaired automatically and flagged as fixed. Valid documents report statistics: total keys, nesting depth and a breakdown of objects, arrays, strings, numbers, booleans and nulls.

JWT decoder and encoder — #jwt

Decode a JSON Web Token into its header, payload and signature, with the standard claims analysed: issuer, subject, audience, JWT ID and the exp, iat and nbf timestamps rendered as readable dates. Expired tokens, tokens that are not yet valid, and unsigned alg: none tokens are called out. Encode mode builds an unsigned token for testing; signing needs a secret key and belongs on a server, never in a browser.

Frequently asked questions

How do I compare two JSON or YAML files?

Open the Diff tab, put the original document on the left and the new version on the right. The tool auto-detects JSON or YAML, then shows every added, removed, modified and type-changed key in a collapsible tree. You can compare a JSON document against a YAML one directly.

Can I load a JSON response straight from an API or a curl command?

Yes. The Diff tab has a request field above each panel. Paste a URL or a full curl command and press Fetch, or use Fetch Both to pull both sides at once. Requests are sent straight from your browser, so APIs that do not send CORS headers need a proxy you deploy yourself; the project ships one for Cloudflare Workers and one for local use.

Can I merge or revert individual differences?

Yes. Hover any difference in the diff tree and use the arrow buttons to copy that value from one side to the other. Single values use the left and right arrows; whole objects and arrays use L→R and R→L.

How do I convert JSON to YAML or YAML to JSON?

Use the Convert tab. Paste either format into the input and pick the output format. Conversion happens as you type and the result can be copied with one click.

How do I decode a JWT token?

Open the JWT tab in Decode mode and paste the token. The header, payload and signature are split out and the standard claims are analysed, including issuer, subject, audience and the exp, iat and nbf timestamps.

How do I check whether a JWT has expired?

Paste the token into the JWT tab. The exp claim is compared against the current time and the status is shown as valid, expired, or not yet valid, alongside the human-readable expiry date.

Can I create a JWT with this tool?

You can build an unsigned JWT for testing: switch the JWT tab to Encode mode and edit the header and payload. The signature segment is left empty because signing requires a secret key, which should never be handled in a browser. Sign tokens server-side for any real use.

Can I edit JSON directly in a tree view?

Yes. The Editor tab renders the document as an interactive tree. Click a value to edit it in place, click a key to rename it, use the plus button to add a string, number, boolean, null, object or array, and the delete button to remove a node.

Is my data sent to a server?

No. Parsing, diffing, conversion and JWT decoding all run in your browser, and the app has no backend. The only network request the tool makes is one you explicitly trigger with the Fetch button in the Diff tab, which goes directly to the URL you supplied.

Is JSON/YAML Toolkit free?

Yes. It is free and open source under the MIT licence, with no account, no ads and no usage limits.
